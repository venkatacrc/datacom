Keyboard shortcuts

On a phone, swipe a lesson or card left or right. While editing code, the key bar above the keyboard has Tab, brackets and cursor keys.

1–4Learn / Cards / Code / Progress
← →Previous / next lesson, card or problem
SpaceCards, Test: show the answer
G / MTest: got it / missed it
K / RMark the card known / for review
⌘/Ctrl EnterRun the code
⌘/Ctrl /Comment or uncomment lines
Tab / ⇧TabIndent / dedent
/Search
EscLeave the editor, close the menu
